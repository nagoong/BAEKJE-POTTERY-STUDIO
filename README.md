# BAEKJE POTTERY STUDIO

백제 토기를 관찰하고 나만의 토기를 구성해 기록하는 한국어 웹 체험 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열면 실행됩니다. 빌드 도구나 패키지 설치는 필요하지 않습니다.

## 화면과 기능

- 홈: 서비스 소개와 제작실 진입
- 전시실: 시대별 예시 유물 정보, 유물 이동, 유물 해설
- 제작실: 기본 형태·세부 형태·문양을 선택하는 4단계 제작 흐름
- 비교하기: 샘플 유물과 제작 모형의 형태 정보를 나란히 확인하고 메모 작성
- 기록실: 브라우저 로컬 저장소에 제작물 보관, SVG 이미지와 JSON 기록 내려받기

## 현재 데이터 범위

프로젝트 폴더에는 3D 스캔 모델, API 명세의 필드, 백엔드 주소가 제공되지 않았습니다. 따라서 이 프로토타입은 토기 형태를 나타내는 SVG 모형과 교육용 예시 유물 정보를 사용합니다. 유물 해설은 예시 문구이며 외부 AI API 호출, 실제 3D 회전/확대, 계정 동기화 기능은 연결되어 있지 않습니다. 실물 유물 정보와 스캔 파일이 확정되면 `app.js`의 `relics` 데이터와 `potSVG` 렌더링 부분을 실제 데이터/3D 뷰어로 교체할 수 있습니다.
