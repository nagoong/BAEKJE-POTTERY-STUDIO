# BAEKJE POTTERY STUDIO

백제 토기를 관찰하고 나만의 토기를 구성해 기록하는 한국어 웹 체험 프로토타입입니다.

## 실행

프로젝트 폴더에서 `node server.js`를 실행한 뒤 `http://localhost:4173`을 엽니다. Node 서버가 웹 화면과 API를 함께 제공합니다.

## 화면과 기능

- 홈: 서비스 소개와 제작실 진입
- 전시실: 시대별 예시 유물 정보, 유물 이동, 유물 해설
- 제작실: Three.js 회전형 3D 토기, 기종별 형태 선택, 토기 색상 변경, 표면 캔버스에 직접 그리는 장식
- 비교하기: 샘플 유물과 제작 모형의 형태 정보를 나란히 확인하고 메모 작성
- 기록실: API 서버에 제작물을 저장하고 SVG 이미지와 JSON 기록 내려받기

## 현재 데이터 범위

기본 제작 모형과 비교 화면은 선택 사항을 반영하는 Three.js 회전형 토기입니다. 제작실을 나가면 진행 중인 제작 상태를 초기화하며, 저장 기록에는 다시 만들 수 있도록 세부 옵션도 함께 보존합니다. 유물 목록은 `data/relics.json`에서 API로 제공하고, 제작 기록은 `data/creations.json`에 저장합니다. 전시실에는 직구단경호·고배·삼족토기·심발형토기 네 종류가 있습니다. `assets/relics/`의 사진은 제공된 PPT에서 가져온 참고 자료이며, 첫 세 기종의 3D 모형은 사진과 형태 설명을 바탕으로 만든 개략적인 회전형 모델입니다. 특정 유물의 정밀 스캔으로 오인되지 않도록 화면에 참고 모델임을 표시합니다. 제공된 OBJ는 직구단경호가 아니라 심발형토기로 등록하며, 파일에 포함된 정점 색상을 사용합니다. 전시실에서 별도 OBJ를 직접 선택할 수도 있습니다.

API 경로, 요청/응답 예시 및 제한사항은 [API_SPEC.md](./API_SPEC.md)를 참고하세요. 이 로컬 MVP에는 인증과 운영용 데이터베이스가 없으므로 공개 인터넷에 그대로 배포하지 마세요.

## 스캔한 OBJ 파일 넣는 방법

1. 스캔 소프트웨어에서 모델을 `.obj` 형식으로 내보내고, 텍스처가 있다면 `.mtl`과 이미지 파일도 함께 준비합니다.
2. 프로젝트 루트의 `models/` 폴더를 만들고 파일을 넣습니다.
3. 전시실의 **스캔 OBJ 모델 열기** 버튼에서 OBJ를 선택합니다. OBJLoader가 로컬 파일을 읽어 Three.js 뷰어에 표시합니다.
4. 실제 서비스에서는 OBJ를 배포 서버에 올려 `relics` 항목의 `objUrl`에 경로를 지정하는 방식이 안정적입니다.

예시:

```js
{
  id: "sinbal",
  name: "심발형토기",
  objUrl: "./models/kimnagyeong-final.obj"
}
```

OBJ만으로도 표시할 수 있지만 재질을 보존하려면 모델과 함께 `.mtl`을 올리고, 생성된 OBJ의 `mtllib`과 텍스처 경로가 올바른지 확인해야 합니다. 외부 주소에 있는 OBJ를 사용할 경우 서버의 CORS 설정도 확인하세요.
