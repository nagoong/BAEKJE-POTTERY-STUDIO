# BAEKJE POTTERY STUDIO

백제 토기를 관찰하고 나만의 토기를 구성해 기록하는 한국어 웹 체험 프로토타입입니다.

## 실행

`index.html`을 브라우저에서 열면 실행됩니다. 빌드 도구나 패키지 설치는 필요하지 않습니다.

## 화면과 기능

- 홈: 서비스 소개와 제작실 진입
- 전시실: 시대별 예시 유물 정보, 유물 이동, 유물 해설
- 제작실: 기본 형태·세부 형태·문양을 선택하는 4단계 제작 흐름
- 비교하기: 샘플 유물과 제작 모형의 형태 정보를 나란히 확인하고 메모 작성
- 기록실: 브라우저 로컬 저장소에 제작물 보관, SVG 이미지와 JSON 기록 내려받기

## 현재 데이터 범위

프로젝트 폴더에는 실제 스캔 모델과 백엔드 주소가 제공되지 않았습니다. 따라서 기본 제작 모형은 SVG로, 유물 해설은 기획서의 핵심 내용을 바탕으로 구성했습니다. 전시실에서는 OBJ 파일을 브라우저에 직접 선택하여 Three.js 뷰어로 관찰할 수 있으며, 실제 유물 데이터가 확정되면 `app.js`의 `relics` 항목에 스캔 파일 경로와 검증된 유물 정보가 지정되어야 합니다.

## 스캔한 OBJ 파일 넣는 방법

1. 스캔 소프트웨어에서 모델을 `.obj` 형식으로 내보내고, 텍스처가 있다면 `.mtl`과 이미지 파일도 함께 준비합니다.
2. 프로젝트 루트의 `models/` 폴더를 만들고 파일을 넣습니다.
3. 전시실 또는 제작실의 **OBJ 파일 선택** 버튼에서 업로드합니다. OBJLoader가 로컬로 선택한 파일을 읽어 Three.js 뷰어에 표시합니다.
4. 실제 서비스에서는 OBJ를 배포 서버에 올려 `relics` 항목의 `objUrl`에 경로를 지정하는 방식이 안정적입니다.

예시:

```js
{
  id: "jar",
  name: "직구단경호",
  objUrl: "./models/jikgu-dangyeongho.obj"
}
```

OBJ만으로도 표시할 수 있지만 재질을 보존하려면 모델과 함께 `.mtl`을 올리고, 생성된 OBJ의 `mtllib`과 텍스처 경로가 올바른지 확인해야 합니다. 외부 주소에 있는 OBJ를 사용할 경우 서버의 CORS 설정도 확인하세요.
